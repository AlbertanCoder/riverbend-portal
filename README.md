# Village of Riverbend — Public Portal (static site)

Static front end for the Riverbend municipal records demonstration.

**Architecture:** this site is hosted on GitHub Pages. The application
server, database, account credentials, and all records live on a private
VPS — none of that is stored in this repository.

- Public site: this repository (GitHub Pages)
- API server: `https://38.253.124.176:8443` (private VPS, CORS-locked to this site)

All data on the API server is synthetic. Demonstration only.
